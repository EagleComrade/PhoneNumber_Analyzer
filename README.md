# PhoneNumber_Analyzer
Hey, I am EagleComrade
This project is a simple Flask-based web application that empowers users to analyze phone numbers efficiently. By leveraging the phonenumbers API, the tool extracts and displays crucial details about phone numbers, including their country, region, and validity.
